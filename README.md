
Blinkit Sales Analysis Dashboard (Power BI)

This project is a sales performance analysis of Blinkit using Power BI. It covers sales trends, customer feedback, product category performance, delivery performance, and marketing metrics.

Objective:
- Analyze sales performance, customer behavior, and delivery metrics.
- Track marketing effectiveness through conversions and ROAS.

Dashboard Visuals Used:
- Tree Map: No. of Items by Category
- Line Chart: Total Sales by Year, Quarter, Month
- Bar Chart: Total Sales by Product Name
- Pie Chart: Customer Feedback Sentiment
- Donut Chart: Customer Segmentation
- Bar Chart: Order Count by Delivery Status
- Line Chart: Avg Delivery Time Over Time
- Column Chart: Conversions by Channel & Audience
- KPI Cards: Total Sales, Avg Sales, Customer Rating, Total Customers, ROAS

Key Metrics:
- Total Sales: ₹4.97M
- Average Sales: ₹994.48
- Avg Customer Rating: 3.34
- Total Customers: 3K
- Revenue Growth: 51.62K
- ROAS: 26.24

Tools Used:
- Power BI Desktop
- Power Query
- DAX

How to Use:
1. Open project1.pbix in Power BI Desktop.
2. Connect to data if needed and refresh.
3. Use visual filters to explore metrics.
